# Maps

An interactive 3D globe for Android, drawn with OpenGL ES 2.0 behind a Jetpack Compose overlay.
It has no third-party libraries, no Play Services and no API key.

## Features

- **Political map**: countries filled from Natural Earth data, with sharp vector coastlines
  and borders.
- **Satellite view**: NASA Blue Marble imagery lit by the real sun. It shows the night side
  with city lights, clouds, sun glint on the oceans and a warm band at dusk. Sharper tiles
  stream in from NASA GIBS as you zoom in. They are cached in memory and on disk, so areas
  you have already seen work offline. A second toggle turns the real sun off, giving
  daylight everywhere.
- **Gestures**: drag to turn the globe, fling to spin it, pinch to zoom. Double tap flies to
  a place; double tap again at full zoom to go back out.
- **Capitals tour**: the camera flies along great circles between 15 world capitals and
  pauses on each one.
- **Locate me**: a dive onto your position, named by the platform geocoder. It also plays
  at launch once location is allowed.

The UI text is in French.

## Build and run

The project needs Android Studio (AGP 9.3, Gradle 9.5, JDK 21) and Android SDK 36.1. The
minimum Android version is 12L (API 32).

```sh
./gradlew installDebug        # build and install on a connected device
./gradlew testDebugUnitTest   # JVM unit tests (geometry, camera, tiles)
```

## Code layout

```
app/src/main/java/com/example/maps/
├── MainActivity.kt          single activity, edge-to-edge
├── ui/                      Compose overlay: captions, buttons, permission flow
├── location/UserLocator.kt  position (LocationManager) and place name (Geocoder)
└── globe/
    ├── GlobeView.kt         GLSurfaceView: gestures, tour, sun refresh
    ├── GlobeCamera.kt       camera state and animations (pure Kotlin, unit tested)
    ├── Flight.kt            great-circle camera flights (cruise and dive)
    ├── GlobeRenderer.kt     draw passes: halo, sphere, tiles, lines, markers
    ├── Shaders.kt           GLSL sources (lighting, day and night, clouds, glint)
    ├── Sun.kt               subsolar point from the date
    ├── WorldData.kt         reader for assets/world.bin
    └── tiles/               satellite tiles: selection, loading, caching, GPU upload
```

The camera and the math are plain Kotlin without Android dependencies, so they are tested
on the JVM. The renderer reads a snapshot of the camera once per frame. It only draws when
asked (`RENDERMODE_WHEN_DIRTY`), and it keeps asking for frames while something is animating.

## Assets

The files in `app/src/main/assets` are generated by the scripts in `tools/`. Run the scripts
from the repository root:

| File | Source | Script |
|---|---|---|
| `world.bin` | Natural Earth 1:50m admin-0 countries | `tools/build_world_asset.py` |
| `earth_day.jpg` | NASA Blue Marble | `tools/fetch_satellite_textures.sh` |
| `earth_night.jpg` | NASA Earth at Night | `tools/fetch_satellite_textures.sh` |
| `earth_clouds.jpg` | Natural Earth III clouds, Tom Patterson | `tools/fetch_satellite_textures.sh` |

The format of `world.bin` is documented at the top of `build_world_asset.py`.
